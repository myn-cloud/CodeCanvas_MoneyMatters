# QuantumWealth – Financial Management Dashboard

QuantumWealth is an interactive financial dashboard designed to demonstrate money management, portfolio monitoring, capital allocation, and risk analysis through a modern, cyber-themed interface. Developed using HTML, CSS, and JavaScript, it provides a visual platform for exploring financial data and simulated investment strategies.

## Features

- **Interactive Dashboard:** Displays simulated financial metrics, portfolio performance, and market activity.
- **Bison and Bear Monitoring:** Represents potential growth opportunities and financial risks.
- **Portfolio Analytics:** Visualizes financial trends and simulated investment performance using interactive charts.
- **Capital Allocation:** Demonstrates the distribution of virtual funds across financial categories.
- **AI-Style Financial Advisor:** Provides sample responses based on user-entered keywords.
- **Market Simulation:** Generates sample market movements and financial indicators.
- **Audit Ledger:** Displays simulated financial activities.
- **Responsive Design:** Offers a user-friendly interface for desktop and mobile devices.

## Technologies Used

- HTML5 and CSS3
- Tailwind CSS
- JavaScript
- Chart.js
- Lucide Icons

## Getting Started

1. Clone or download the repository.
2. Open the project folder.
3. Launch the HTML file in a modern web browser.
4. Explore the dashboard and its interactive features.

## Project Objective

The main objective of QuantumWealth is to demonstrate how modern web technologies can support financial visualization, money management concepts, investment allocation, and risk monitoring through an interactive dashboard.

## Future Enhancements

Future improvements may include real-time market data, expense tracking, savings goal management, secure authentication, persistent storage, and advanced portfolio analytics.

## Disclaimer

QuantumWealth currently uses simulated financial data. It does not connect to real bank accounts, execute financial transactions, or provide verified investment advice. The project is intended for educational and demonstration purposes only.
